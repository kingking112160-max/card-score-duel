# 1:1 블랙잭 점수 대결 최종 UI 버전

## 규칙
- 8덱
- S17
- 같은 딜러 핸드 공유
- 각자 HIT / STAND / DOUBLE / SPLIT 독립 선택
- 20초 액션 제한
- 일반 승리 +1
- 패배 / BUST -1
- PUSH 0
- DOUBLE 승리 +2 / 패배 -2 / PUSH 0
- SPLIT은 각 핸드 개별 정산 후 합산
- 먼저 +15점 도달 = 승리
- 먼저 -15점 도달 = 패배
- 라운드 제한 없음
- 새 매치 시 새 8덱 슈

## 화면
- 본인 플레이 영역은 겨자색
- 상대 영역은 검은색
- 양쪽 카드 모두 확인 가능
- 카드 크기 확대
- ROUND 아래에 남은 시간 표시
- +15 / -15 규칙을 상단 중앙에 배치
- 안내 문구는 테이블 맨 아래
- 모바일 반응형 지원

## 실행
1. npm install
2. npm start
3. 블랙잭 킹: http://localhost:3000/king
4. 도전자: http://localhost:3000/join

## 방 생성
블랙잭 킹이 /king 에서 방 비밀번호를 정하고 새 방 만들기를 누르면
6자리 방 코드와 /join?room=XXXXXX 링크가 생성됩니다.


## 최신 UI 변경
- 카드 숫자/문양 크게 확대
- 좌측 점수 규칙 / 우측 게임 규칙 패널
- 새 매치 클릭 시 확인 팝업
- 팝업에서 취소하면 아무 변화 없음
- SPLIT으로 핸드가 늘어나도 플레이어 영역 내부에서만 스크롤/배치되어 딜러 영역을 가리지 않음

- 새 매치 확정 시 현재 도전자는 자동 로그아웃되어 /join 화면으로 이동

- SPLIT 시 내부 스크롤 제거
- 2핸드는 자동 2열 배치
- 3~4핸드는 2x2 형태로 자동 축소 배치
- 카드 크기를 핸드 수에 맞춰 자동 조정해 한 화면에서 모두 확인 가능

- SPLIT 이후 현재 플레이 중인 핸드에 금색 강조 테두리 표시
- 현재 플레이 중 핸드 위에 '현재 플레이' 배지 표시
- HAND n · ACTIVE 문구 강조
- 양쪽 화면에서 동일하게 현재 진행 핸드 확인 가능

- 4핸드(3회 스플릿) 전용 초압축 레이아웃 추가
- 4핸드를 2x2 고정 배치
- 카드/합계/ACTIVE 배지 자동 축소
- 내부 스크롤 없이 4핸드 전체 표시

- 4핸드 PC 레이아웃을 2x2에서 1x4 가로 한 줄로 변경
- 3회 스플릿 시 아래로 밀리지 않도록 카드/간격 자동 초압축
- 모바일에서만 2x2 유지

- SPLIT은 플레이어당 한 라운드 최대 2회
- 최대 3핸드까지 생성 가능
- SPLIT 버튼에 사용 횟수 표시
- 2회 사용 시 SPLIT · MAX로 비활성화

- SPLIT 제한을 최대 1회로 변경
- 한 라운드에서 플레이어당 최대 2핸드
- SPLIT (0/1) → 사용 후 SPLIT · MAX

- +15 도달 또는 -15 도달로 게임 종료 시 최종 승자 팝업 표시
- 예: '블랙잭 킹 승리!' 또는 '닉네임 승리!'
- 블랙잭 킹/도전자 양쪽 화면에 동시에 표시

- 플레이어 내추럴 블랙잭 승리: +2점
- 딜러 블랙잭: 해당 라운드 즉시 종료
- 딜러 업카드 A: 양쪽 플레이어에게 INSURANCE 단계 제공
- INSURANCE 선택 즉시 -1점
- 딜러가 블랙잭이면 보험 선택자에게 +1점 반환
- 보험 미선택/시간초과는 보험 안함 처리
- 딜러와 플레이어 모두 블랙잭이면 해당 플레이어는 PUSH 0점

- 점수 변경 시 +1 / -1 / +2 / -2가 플레이어 영역 위에 크게 애니메이션으로 표시
- 점수 상승은 초록색 글로우, 점수 하락은 빨간색 글로우
- 도전자 링크 옆에 '도전자 링크 복사' 버튼 추가
- 새 매치 확정 시 도전자 로그아웃
- 새 매치 확정 시 블랙잭 킹도 기존 방이 완전히 종료되고 /king 첫 화면으로 이동
- 블랙잭 킹은 새 방 비밀번호부터 다시 설정하여 새 ROOM CODE를 발급

- 새 매치 확정 시 기존 ROOM CODE 폐기
- 새 매치마다 기존 코드와 다른 신규 6자리 ROOM CODE 자동 생성
- 도전자 참가 링크도 새 ROOM CODE가 포함된 링크로 즉시 변경
- 링크 복사 버튼은 항상 새 링크를 복사
- 기존 도전자는 로그아웃되며 새 링크로 다시 입장해야 함
- 블랙잭 킹은 페이지를 나가지 않고 새 방에서 바로 대기

- 중복 점수 규칙 제거: 상세 점수 규칙은 좌측 패널 한 곳에서만 표시

- A,A 스플릿 규칙 추가
- A,A 스플릿 후 각 핸드에 카드 1장씩만 지급
- 해당 두 핸드는 즉시 종료
- 스플릿 A 핸드에서는 HIT / STAND / DOUBLE / 추가 SPLIT 불가
