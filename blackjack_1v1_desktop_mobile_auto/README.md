# 1:1 블랙잭 최신 통합판

핵심 변경:
- 새 매치 클릭 시 새 비밀번호 입력
- 확인 후 기존 방 폐기
- 새로운 6자리 ROOM CODE 생성
- 새로운 도전자 링크 생성
- 기존 도전자 자동 로그아웃
- 딜러 A 업카드 인슈어런스 단계에서 홀카드 완전 비공개
- 플레이/인슈어런스 중에는 업카드만 공개
- 결과 단계에서만 딜러 전체 카드 공개

기존 유지 기능:
- 점수 애니메이션
- 링크 복사
- SPLIT 최대 1회
- A,A SPLIT 후 각 핸드 1장씩만 받고 종료
- 플레이어 내추럴 블랙잭 +2
- 딜러 블랙잭 즉시 라운드 종료
- INSURANCE 선택 즉시 -1, 딜러 BJ면 +1 반환
- +10 승리 / -10 패배
- 최종 승자 팝업
- 8덱 / S17 / 20초


## 최신 변경
- INSURANCE 기능 완전 제거
- 딜러 업카드가 A 또는 10/J/Q/K이면 서버가 홀카드를 즉시 피크
- 홀카드가 10점/A 조합으로 블랙잭이면 즉시 라운드 종료
- 피크 중 홀카드는 플레이어 화면에 공개되지 않음
- 딜러 블랙잭 확정 또는 일반 라운드 결과 이후에만 홀카드 공개

## 기기별 UI
- 같은 URL을 사용합니다.
- PC/노트북(폭 851px 이상): 기존 데스크탑 카지노 테이블 UI.
- 휴대폰(폭 850px 이하): 자동 모바일 앱형 UI.
- 모바일은 화면 스크롤 없이 라운드/시간, 딜러, 양쪽 플레이어, 액션 버튼을 한 화면에 맞추도록 압축됩니다.
- 모바일에서도 1회 SPLIT의 두 핸드를 동시에 표시합니다.


## 최신 변경
- 최종 승패 기준을 +10 / -10으로 단축
- 최초 카드 6장을 약 0.42초 간격으로 한 장씩 배분
- HIT / DOUBLE로 추가되는 새 카드에 딜링 애니메이션 적용
- 플레이 종료 후 딜러 홀카드를 먼저 공개하고, 추가 카드를 약 0.5초 간격으로 한 장씩 진행
- 데스크탑/모바일 모두 동일한 카드 등장 애니메이션 적용

- 플레이어 점수 위에 '현재 점수' 표시 및 점수 크기 확대
- 홀카드 비공개 시 딜러는 '딜러 공개 점수'로 업카드 점수만 표시
- 딜러 카드 공개 후 '딜러 현재 점수'로 전체 합계 표시
- 두 플레이어가 공유하는 공용 20초 액션 타이머
- 누가 액션해도 타이머는 20초로 리셋되지 않음
- 20초 종료 시 미완료 핸드는 자동 STAND
- 라운드 종료 후 5초 카운트다운 뒤 다음 라운드 자동 시작
- 수동 다음 라운드 버튼 제거

- 플레이어 카드 크기를 소폭 축소하되 숫자/문양 크기는 유지
- 각 핸드 아래 '카드 점수 N'을 크게 표시
- '같은 딜러를 상대합니다...' 하단 상태 문구 삭제
- 삭제한 공간만큼 플레이어 겨자색/검정 박스를 아래로 확장
- 모바일에서 카드 하단이 잘리지 않도록 플레이어 영역/카드 높이 재조정
- 모바일 SPLIT 2핸드도 한 화면에서 보이도록 별도 축소 레이아웃 적용

- 카드가 안 나오던 원인 수정: 삭제된 status DOM 접근으로 render()가 중단되던 오류 제거
- 도전자 닉네임 표시 정상화
- 라운드 종료 후 중앙 대형 팝업으로 5초 카운트다운 표시

- 모바일 카드 FULL-FIT: 양 플레이어를 좌우 배치하고 카드/딜러/버튼을 모바일 화면에 맞게 압축

- 모바일 Chrome/Safari 하단 툴바를 피하도록 액션 버튼을 약 90~100px 위로 이동
- iPhone safe-area inset 반영

- 모바일 액션바 선택자를 실제 DOM 구조(.control-panel .buttons) 기준으로 수정
- iPhone Chrome 하단 툴바 위 90~104px 위치에 고정
